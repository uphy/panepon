# panepon

パネルでポン（Panel de Pon）風のアクションパズルのクローン。ブラウザで動く。

- ゲームロジックは `src/core/` に閉じ込めた純粋な TypeScript。DOM・Phaser に依存しない
- 描画・入力・音は `src/render/` で Phaser 4 を使う。画像・音声ファイルは使わず、すべてコードで生成する
- スマホの高解像度画面でぼやけないよう、canvas は論理サイズ × devicePixelRatio で作り、カメラの zoom で論理座標を保つ（`src/render/hidpi.ts`）
- 60fps の固定 tick で進む決定論的シミュレーション。同じ seed と入力列なら同じ結果になる

## 動かす

```sh
pnpm install
pnpm dev          # http://localhost:5173
pnpm test         # コアのユニットテスト（vitest）
pnpm e2e          # ブラウザでの動作確認（Playwright、headless Chromium）
pnpm build        # dist/ に静的ファイルを出力
```

初回の e2e には `pnpm exec playwright install chromium` が必要。

URL パラメータで直接ゲームを始められる。

| パラメータ | 意味 |
|---|---|
| `?mode=endless` / `?mode=versus` / `?mode=cpu` | メニューを飛ばして開始 |
| `&cpu=easy` / `normal` / `hard` | CPU の強さ（`mode=cpu` のとき） |
| `&shock=0` | 対戦でビックリパネルを出さない。数値で1試合の上限枚数を指定 |
| `&seed=123` | 盤面の乱数 seed |
| `&speed=10` | 開始スピードレベル（1〜99） |
| `&bgm=0` | BGM を鳴らさない |
| `&countdown=0` | 開始時の 3・2・1 カウントダウンを飛ばす |

## 操作

| | 1P | 2P |
|---|---|---|
| カーソル移動 | ←↑↓→ | W A S D |
| 入れ替え | Z / Space / Enter | F / G |
| 手動せり上げ | X / Shift | H / R |

ゲームパッドは1台目が1P、2台目が2P。十字キー・左スティックで移動、A/B で入れ替え、L/R で手動せり上げ。

P で一時停止、R でやり直し、Esc でメニュー、M でミュート（ミュートは localStorage に保存）。

### タッチ・マウス

- 2枚のパネルの境目をタップすると、その2枚が1回で入れ替わる。マスの中央を叩いたときは近い側の隣と入れ替わる
- パネルを横にドラッグしても入れ替わる。指を離さず引き続ければ連続で入れ替わる
- 盤面の外（下の余白や脇）を押し続けると手動せり上げ。盤面の下の「▲ ▲ ▲」が押している間だけ明るくなる。対戦では左右どちらの盤面に近いかで振り分ける
- 縦持ちのスマホでは盤面が画面幅いっぱいになるレイアウトに切り替わる。CPU 対戦は自分の盤面をエンドレスと同じ大きさで描き、CPU の盤面は右に半分の大きさで添える。2P 対戦は同じ大きさの2盤面を並べる
- 盤面の右上の「❚❚」でポーズ。ポーズ画面に RESUME / RESTART / SOUND / VIBRATION / MENU のボタンがある。終了後は盤面に RETRY / MENU が出る
- 端末を回転すると、ゲームを止めずに横向き・縦向きのレイアウトへ置き直す
- ノッチやホームインジケータの内側（safe area）に収める
- 振動フィードバック（Android など `navigator.vibrate` のある端末）。揃った瞬間・おじゃまの着地・天井接触・終了で震える。自分の盤面だけで、CPU の盤面では震えない。メニューの VIBRATION で切り替え、キーボードなら V。iOS Safari は API がないので何も起きない。Android はサイレントモード（マナーモード）だと OS が振動を止めるので、鳴らない場合はまず音量モードを確認する。`/vibrate-test.html` でゲームを介さずに試せる

### モード

- **1P ENDLESS**: 消した枚数でスピードレベルが上がる。上位5件のスコアを localStorage に保存し、メニューにベストを表示する
- **VS CPU**: EASY / NORMAL / HARD の CPU と対戦。勝敗数を保存する。CPU は人と同じ制約（カーソルを1マスずつ動かし、カーソル位置でだけ入れ替える）で動き、難易度は思考の待ち時間・カーソル速度・1手先の連鎖読み・仕込みの有無で差をつけている（`src/core/ai.ts`）
- **2P VERSUS**: 同じキーボードかゲームパッド2台での対戦

スマホで遊ぶときは、同じ Wi-Fi にいる状態で Mac 側を `pnpm dev --host` で起動し、表示される `Network:` の URL をスマホのブラウザで開く。

### PWA

- ビルドすると manifest と Service Worker（vite-plugin-pwa）が付き、Android Chrome は「ホーム画面に追加」でインストールできる。iOS は Safari の共有メニューから「ホーム画面に追加」で全画面になる
- 一度開けば、Service Worker がビルド成果物を丸ごと precache するので、次回からはオフラインでも遊べる。新しい版は次に開いたときに切り替わる
- アイコンは `node tools/make-icons.mjs` がコードから PNG を生成する（`public/icons/`）。画像ファイルを手で描くことはしない
- iOS はサイレントスイッチ（本体横のスイッチ）が ON だと WebAudio の音が全部消える。音が出ないときはまずここを確認する

## 実装している仕様

原作（SFC版）の公開情報とファンサイトの実測値を元にしている。

- 6列×12段、下からせり上がる盤面。次にせり上がる行は暗く表示
- 横2マスのカーソルで隣接する2枚（またはパネルと空白）を入れ替える。入れ替えは4フレーム
- 同じ柄が縦横3枚以上で消える。消去中はせり上がりが止まる
- 同時消し（4枚以上）と連鎖。消去で落ちたパネルにだけ連鎖フラグが付く
- アクティブ連鎖。消去中・落下中も入れ替えを受け付ける
- 時間差連鎖。別々に着地した2組が「2, 3」と数えられる
- 得点表はファンサイトの実測値。3枚消しの13連鎖で累計9,170点、14連鎖以降のボーナスは0、31個消しは0点
- 手動せり上げは1段1点。停止表示中の最初の1段は0点
- 対戦: 同時消し n個 で幅 n-1 の板、n連鎖で幅6・厚さ n-1 の板（上限12段）。8個以上は分離
- おじゃまパネルは隣接するパネルを消すと変身。厚さ1段は全部、厚い板は下1段だけ通常パネルになる
- 変身で出たパネルには連鎖フラグが付くので、おじゃま返しが成立する
- ビックリパネル（対戦専用の「！」付き灰色パネル）。12枚消すごとにせり上がり行へ1枚混ざり、1試合24枚まで。ビックリパネル同士が3枚以上揃うと「消した枚数−2」枚の灰色の板（幅6・厚さ1段）を送る。灰色のおじゃまと通常のおじゃまは同時に変身しないので、交互に積むとサンドイッチになる
- 天井に触れても消去中・変身中はゲームオーバーにならない。猶予を過ぎるとゲームオーバー
- 上2段にパネルが入ると危険状態になり、BGM のテンポが上がる

未実装: ステージクリア・パズルモード、キャラクター。

## 構成

```
src/core/       ゲームロジック（Board, Game, CPU プレイヤー, 得点表, おじゃま仕様）
src/render/     Phaser のシーン・描画・入力・音
tests/core/     vitest によるロジックのテスト（ランダム入力の長時間実行も含む）
e2e/            Playwright によるブラウザ動作確認とスクリーンショット
```

タイミングは `src/core/constants.ts` の `TIMING` にフレーム数でまとめてあり、手触りの調整はここを変える。消去の点滅・柄を見せる時間・1枚ずつ消える間隔・落下前の猶予は `clearTiming(level)` でスピードレベルに応じて短くなる（レベル1が最長、レベル50以上で最短）。
